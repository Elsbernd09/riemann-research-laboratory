# Phase 4A Li Blind-Scale Interpretation

## Research question

Does the explicit Li susceptibility profile imply a mathematical consequence beyond a leading scaling collapse?

## Result

Yes, at the individual-kernel level.

The profile

\[
\Psi_{\mathrm{Li}}(c)
=
-2c(c\cos c+2\sin c)
\]

has infinitely many positive simple zeros.

There is exactly one positive nonzero root

\[
c_k
\]

in each interval

\[
\left(
\left(k+\frac12\right)\pi,
(k+1)\pi
\right).
\]

These roots satisfy

\[
\tan c_k=-c_k/2.
\]

The project calls them quadratic-response blind scales for the individual Li zero kernel.

---

# Refined susceptibility

For

\[
q=n/\gamma,
\]

the susceptibility admits the candidate two-term expansion

\[
\chi_n^{\mathrm{Li}}(\gamma)
=
\gamma^{-2}
\Psi_{\mathrm{Li}}(q)
+
\gamma^{-4}
K_{\mathrm{Li}}(q)
+
O_q(\gamma^{-6}).
\]

At an exact profile zero,

\[
q=c_k,
\]

the leading order vanishes and

\[
\chi_n^{\mathrm{Li}}(\gamma)
\asymp
\gamma^{-4}.
\]

Thus an exact matched blind scale gains two height-decay powers relative to the generic response.

---

# Near-blind hierarchy

If

\[
n/\gamma-c_k
\sim
\beta\gamma^{-r},
\]

the candidate effective exponent is

\[
2+\min(r,2)
\]

unless a displayed leading coefficient cancels.

This creates a transition hierarchy controlled by the rate at which the parameter-height path approaches a response-profile zero.

---

# Negative optimization result

The leading Li profile is unbounded in magnitude.

Therefore there is no unconstrained global maximizer of response magnitude over

\[
c>0.
\]

Any statement about an "optimal Li response scale" requires a declared cost or admissible-coordinate constraint.

---

# Research significance boundary

This phase does not establish blind scales for the global Li coefficient sequence.

It establishes profile-degenerate blind scales for the individual-kernel quadratic zero-coordinate response.

The distinction must be preserved.
