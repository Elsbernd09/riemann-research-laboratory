# Phase 5E Independent Discrepancy Decomposition Experiment

## Objective

Independently compute the empirical counting remainder and smooth Li-kernel truncation remainder in dense actual-zero response windows.

## Experimental subset

Complete windows with occupancy at least

\[
25.
\]

## Coordinates

Requested coordinates

\[
c=1,2,\ldots,20.
\]

Integer Li indices are generated by rounding \(cH\), and all computations use the realized value \(n/H\).

## Independent counting-remainder evaluation

The direct value is

\[
R_{\mathrm{count}}^{direct}
=
W-S_{\mathrm{exact}}.
\]

The independent Stieltjes value is

\[
R_{\mathrm{count}}^{Stieltjes}
=
f(H)\Delta N_D(H)
+
f(B)E_D(B)
-
f(H)E_D(H)
-
\int_H^B E_D(t)f'(t)dt.
\]

The derivative \(f'(t)\) is evaluated through an exact analytic formula validated independently against arbitrary-precision numerical differentiation.

Quadrature is split at every internal zero ordinate so the empirical counting remainder is integrated piecewise across its staircase discontinuities.

## Kernel remainder

\[
R_{\mathrm{kernel}}
=
S_{\mathrm{exact}}
-
S_{\mathrm{profile}}.
\]

## Closure test

\[
W-S_{\mathrm{profile}}
=
R_{\mathrm{count}}^{Stieltjes}
+
R_{\mathrm{kernel}}.
\]

## Component comparison

Per-window RMS magnitudes are computed after the Phase 5C normalization

\[
H/\log H.
\]

Counting and kernel component sizes are compared in:

- all dense complete windows;
- the high-occupancy subset with at least 50 zeros.

## Height slopes

Log-log slopes of per-window RMS component magnitude against H are descriptive finite-range fits.

They are not treated as asymptotic exponent estimates without a substantially larger height range.

## Endpoint atom

The left-inclusive statistic is compared with the left-open statistic

\[
W^\circ=W-\chi_n(H).
\]

The ratio of open-window residual RMS to closed-window residual RMS quantifies the effect of removing the explicit anchor atom.
