# Novelty Claim Quarantine

## Effective phase

Phase 3A onward until prior-art disposition is completed.

## Prohibited project descriptions

The following phrases must not be used as factual descriptions of the project's mathematical originality:

- new framework;
- novel taxonomy;
- new susceptibility theory;
- previously unknown;
- first-ever;
- new approach to the Riemann Hypothesis;
- progress toward solving the Riemann Hypothesis;
- breakthrough.

These phrases may appear only when quoted, rejected, or explicitly labeled as unresolved hypotheses about originality.

## Permitted descriptions

The project may state:

"We developed a project-specific comparative formalism."

"The repository investigates whether the formalism provides a useful organizing language."

"Originality remains under active prior-art review."

"The project has internally proved and computationally validated several kernel-specific scaling identities."

"The current results do not imply the Riemann Hypothesis."

## Release rule

A quarantined originality claim may be released only after:

1. the relevant audit question is searched;
2. closest prior art is recorded;
3. evidence grades are assigned;
4. claim disposition is written;
5. the claim ledger is updated.
