# Object Dependency Graph

## Correct reconstruction order

```text
Admissible test-function class
        ↓
Transform convention
        ↓
Explicit formula
        ↓
Weil quadratic functional
        ↓
Positive / negative direction theorem
        ↓
Finite-rank restriction
        ↓
Computational model
```

## Forbidden shortcut

```text
Toy matrix
        ↓
Claimed Weil relevance
```

This shortcut is invalid.

A toy matrix may motivate questions, but it cannot establish a Weil theorem.

## Phase 8B rule

No future phase may claim Weil compatibility until the object dependency graph has been satisfied.
