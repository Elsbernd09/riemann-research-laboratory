# Phase 8C — Exact Classical Formulation Selection

## Purpose

Phase 8A began the classical Weil reconstruction program.

Phase 8B defined the object map.

Phase 8C chooses the exact reconstruction path.

This is not a proof of RH.

This is not a new Weil criterion.

This is not a novelty claim.

It is a formulation-selection phase.

---

# 1. Why a selection is necessary

The phrase "Weil criterion" can refer to several closely related forms:

1. the Weil explicit formula;
2. Weil positivity;
3. Bombieri's quadratic form formulation;
4. Li-type positivity criteria;
5. Guinand-Weil explicit formula variants;
6. operator-theoretic formulations;
7. finite truncation models.

The project cannot responsibly continue unless it selects one formulation to reconstruct first.

---

# 2. Chosen primary formulation

The primary reconstruction path is:

\[
\boxed{
\text{Bombieri-style Weil quadratic form reconstruction.}
}
\]

This path is chosen because it directly addresses the Phase 7 questions:

1. positivity;
2. negative directions;
3. off-critical zero detection;
4. finite truncation behavior;
5. distinction between toy matrices and classical forms.

---

# 3. Why not start with Li coefficients?

Li's criterion is classical and RH-equivalent.

However, the Phase 7 program already explored Li-coordinate horizontal sensitivity.

The problem was not lack of Li-type diagnostics.

The problem was that positive diagnostics were not connected to a classical arithmetic-side positivity mechanism.

Therefore the better next step is not another Li diagnostic.

The better next step is the classical Weil quadratic framework.

---

# 4. Why not start with arbitrary finite matrices?

Phase 7 built useful finite-rank diagnostic matrices.

But Phase 7K showed basis-dependence.

That means arbitrary finite matrices are not enough.

A finite-rank model becomes serious only after it is derived from a classical admissible test-function space and quadratic form.

---

# 5. Reconstruction target

The reconstruction target is to build the following chain:

\[
\text{classical test functions}
\Rightarrow
\text{explicit formula}
\Rightarrow
\text{Weil quadratic form}
\Rightarrow
\text{RH-equivalent positivity statement}
\Rightarrow
\text{off-critical negative-direction mechanism}
\Rightarrow
\text{finite truncation model}.
\]

The project is currently only at the first step.

---

# 6. Known classical status

The following are classical and must not be claimed as new:

- Weil explicit formula;
- Weil positivity criterion;
- Bombieri quadratic formulation;
- RH-equivalence of appropriate positivity statements;
- existence of negative directions when off-critical zeros exist in the classical framework;
- connections between Li coefficients and explicit formulae.

---

# 7. Project-specific future work

Possible project-specific work after reconstruction may include:

1. coding finite truncations of the classical quadratic form;
2. comparing classical negative directions with Phase 7 horizontal-defect toy directions;
3. studying conditioning and convergence of finite truncations;
4. creating visual and numerical laboratories;
5. proving small obstruction lemmas about which toy models cannot be Weil-compatible.

None of this should be called RH progress unless it produces a genuinely new theorem with literature review.

---

# 8. Phase 8C conclusion

The selected path is:

\[
\boxed{
\text{Classical Bombieri/Weil quadratic-form reconstruction first.}
}
\]

No more arbitrary toy models should be added before this reconstruction is done.
