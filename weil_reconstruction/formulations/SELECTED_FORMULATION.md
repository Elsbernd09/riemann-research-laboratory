# Selected Formulation

## Selected path

Bombieri-style Weil quadratic form reconstruction.

## Purpose

Reconstruct the classical positivity framework before creating more finite-rank experiments.

## Why this path

This path directly connects to:

- positivity;
- RH equivalence;
- off-critical zero negative directions;
- finite truncations;
- distinction between toy diagnostics and classical objects.

## What this is not

This is not a new criterion.

This is not a proof of RH.

This is not a novelty claim.

This is not a claim that the project has improved Weil's criterion.

## Current project state

The project has not yet reconstructed the exact admissible test-function class, transform convention, or quadratic functional.

Those are the next tasks.
