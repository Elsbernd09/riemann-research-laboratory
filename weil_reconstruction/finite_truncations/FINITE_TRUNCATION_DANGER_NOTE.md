# Finite Truncation Danger Note

## Main danger

A finite matrix that reacts to off-critical zeros is not automatically a Bombieri-Weil finite truncation.

Phase 7 already demonstrated that finite-rank toy matrices can be basis-dependent.

Therefore, Phase 8 must not confuse:

\[
\text{finite diagnostic matrix}
\]

with

\[
\text{source-derived Bombieri-Weil truncation}.
\]

---

# Forbidden language until extraction is complete

Do not call any new matrix:

- a Bombieri matrix;
- a Weil matrix;
- a classical truncation;
- a finite Weil form;
- an RH-equivalent truncation;
- a negative-direction certificate.

---

# Allowed language

Until source extraction is complete, use:

- toy diagnostic;
- symbolic placeholder;
- extraction target;
- unimplemented classical object;
- source-pending matrix.
