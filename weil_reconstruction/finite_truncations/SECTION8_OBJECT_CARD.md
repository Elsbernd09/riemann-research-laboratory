# Section 8 Object Card

## Source

Bombieri, Section 8, "The eigenvalues of finite approximations."

## Finite multiset

\[
Z
\]

is a finite multiset with zeta-zero-like symmetries.

If

\[
\rho\in Z,
\]

then

\[
\overline{\rho},\ 1-\rho\in Z
\]

with the same multiplicity.

## Gamma notation

\[
\rho=\frac12+i\gamma.
\]

The associated finite multiset is

\[
\Gamma.
\]

## Cutoff

\[
\Phi=1_{[-t,t]}.
\]

## Finite space

\[
V=\operatorname{span}_{\mathbb C}
\left\{
\Phi(x)e^{x/2},
\Phi(x)e^{-x/2},
\Phi(x)e^{-i\gamma x}:\gamma\in\Gamma
\right\}.
\]

## Boundary subspace

\[
V^\circ=
\{F\in V:F(-t)=F(t)=0\}.
\]

## Inner product

\[
(P,Q)=\int_{-\infty}^{\infty}P(x)\overline{Q(x)}\,dx.
\]

## Linear object

\[
L[F](x)
=
\sum_{\gamma\in\Gamma}
\int_{-\infty}^{\infty}
F(x+u)e^{i\gamma u}\,du.
\]
