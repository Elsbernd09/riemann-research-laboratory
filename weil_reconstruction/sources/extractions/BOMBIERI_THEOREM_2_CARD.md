# Bombieri Theorem 2 Card

## Source

Bombieri, Section 3.

## Theorem type

Known theorem reconstructed.

## Statement

Bombieri defines a linear functional

\[
T[f]
\]

on

\[
C_0^\infty((0,\infty)).
\]

It satisfies

\[
T[f]=T[f^*]=\sum_\rho f(\rho).
\]

Moreover, RH is equivalent to

\[
T[f*f^*]\ge0
\]

on

\[
C_0^\infty((0,\infty)),
\]

with equality only for the zero function.
