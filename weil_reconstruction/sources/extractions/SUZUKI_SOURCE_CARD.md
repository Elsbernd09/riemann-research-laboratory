# Suzuki Source Card

## Source

Masatoshi Suzuki, **Weil's Quadratic Form via the Screw Function**, uploaded source excerpt.

## Role in project

Secondary source for modern notation and contextual framing of the Weil quadratic form.

## Extracted high-level facts

1. The source defines or recalls a Weil functional \(W(f)\).
2. It records the Hermitian/symmetric quadratic form

\[
Q_W(v_1,v_2)=W(v_1*\tilde v_2),
\qquad
Q_W(v)=Q_W(v,v).
\]

3. It records the classical RH-equivalent positivity statement

\[
Q_W(v)\ge0
\]

for all

\[
v\in C_c^\infty(\mathbb R).
\]

4. It discusses localized spaces and operator-theoretic refinements.

## Project use

This source helps standardize notation for:

- \(W(f)\);
- \(Q_W\);
- compactly supported smooth test functions;
- localized forms.
