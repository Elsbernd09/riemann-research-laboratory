# Bombieri Theorem 1 Card

## Source

Bombieri, Section 3.

## Theorem type

Known theorem reconstructed.

## Statement

The Riemann Hypothesis holds if and only if

\[
\sum_\rho
g(\rho)g(1-\rho)>0
\]

for every nonzero complex-valued

\[
g\in C_0^\infty((0,\infty)).
\]

## RH-side intuition

Under RH,

\[
1-\rho=\overline{\rho},
\]

so the summands become

\[
|g(\rho)|^2.
\]

## Project use

This theorem clarifies how off-critical zeros enter a quadratic positivity framework.
