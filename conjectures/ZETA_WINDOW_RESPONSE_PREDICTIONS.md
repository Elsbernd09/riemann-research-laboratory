## P-ZETA-001

For fixed positive relative window width eta, individual Li response blind scales c_k will generally not minimize the truncated actual-zero window susceptibility.

Interpretation:

A positive-width height window samples a range of similarity coordinates c/u and should smear single-orbit profile cancellation.

## P-ZETA-002

After normalization by H/log H, high-zero truncated window susceptibility should exhibit broad agreement with the smooth-density profile

\[
\Phi_\eta(c)
=
\frac{c}{\pi}
\left[
(1+\eta)^{-2}
\sin(c/(1+\eta))
-
\sin c
\right].
\]

Status:

HEURISTIC PREDICTION.

No convergence theorem is claimed.
