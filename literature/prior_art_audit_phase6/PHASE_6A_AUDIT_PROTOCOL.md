# Prior-art grades

## PA-0 — Irrelevant

No mathematically meaningful overlap.

## PA-1 — Background ancestor

Provides standard machinery, notation, or surrounding theory.

## PA-2 — Conceptual overlap

Studies a closely related phenomenon but not the same mathematical construction.

## PA-3 — Strong structural overlap

Contains a construction or theorem materially similar to a major project object.

## PA-4 — Subsuming prior art

Contains a mathematically equivalent or stronger construction that subsumes the originality-sensitive project claim.

---

# Disposition rules

A PA-4 source requires immediate downgrade or reclassification of the threatened originality-sensitive claim.

A PA-3 source requires explicit comparison and narrower project language.

A PA-2 source must be discussed as conceptual overlap.

PA-1 sources supply background and attribution.

Keyword absence is never novelty evidence.

Failure to locate a subsuming source is reported only as:

"No subsuming source identified in the current audit."

It must not be reported as:

"Novel."

---

# Search standards

The substantive audit should prioritize primary sources:

- original journal papers;
- original arXiv manuscripts;
- monographs by the original researchers when historically foundational;
- official journal or publisher versions.

Secondary sources may be used for discovery but not as final technical evidence when primary sources are available.

For each important source, record:

- full citation;
- DOI, arXiv identifier, or stable publication identifier;
- primary-source status;
- exact mathematical object;
- theorem, proposition, lemma, or equation number when available;
- closest project object;
- exact overlap;
- exact difference;
- PA grade;
- threatened claims;
- required disposition;
- cited predecessors requiring follow-up.
