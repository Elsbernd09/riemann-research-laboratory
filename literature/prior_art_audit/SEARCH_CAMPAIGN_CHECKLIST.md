# Prior-Art Search Campaign Checklist

For each audit question Q1-Q7:

- [ ] Run exact-object query family.
- [ ] Run ancestor query family.
- [ ] Run RH or application query family where applicable.
- [ ] Search Google Scholar.
- [ ] Search arXiv.
- [ ] Search MathSciNet.
- [ ] Search zbMATH Open.
- [ ] Record exact search strings.
- [ ] Record date of search.
- [ ] Preserve candidate papers opened.
- [ ] Record rejected candidates and rejection reason.
- [ ] Capture retained primary sources.
- [ ] Follow backward citations from the closest source.
- [ ] Follow forward citations where available.
- [ ] Assign PA grade.
- [ ] Identify threatened project claims.
- [ ] Write preliminary disposition.
- [ ] Do not make a novelty conclusion from keyword absence alone.
