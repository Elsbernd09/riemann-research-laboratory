# 1. What was achieved

The breakthrough-push branch achieved the following:

## 1.1 Primary-source validation

Bombieri–Lagarias primary-source conventions were extracted.

Confirmed:

\[
\widetilde f(x)=x^{-1}f(1/x),
\]

\[
(f\vee g)(x)=\int_0^\infty f(xy)g(y)\frac{dy}{y},
\]

and the convolution-square spectral product connected to Weil positivity.

## 1.2 Convention reconciliation

The project proved:

\[
f^*=\widetilde{\bar f}.
\]

This reconciles the project star convention with Bombieri–Lagarias notation.

## 1.3 Normalization correction

The Bombieri–Lagarias displayed explicit formula uses:

\[
-(\log\pi+\gamma)f(1).
\]

The project corrected future arithmetic-entry metadata to track this normalization.

## 1.4 Pole-admissible finite subspace machinery

The project built finite-dimensional pole-removal machinery:

\[
Ca=0,
\]

and

\[
M_{\mathrm{adm}}=N^*MN.
\]

## 1.5 Metadata and certification discipline

The project created:

1. certified entry metadata schema;
2. metadata-only entry;
3. prototype floating-point entry;
4. interval-candidate entry;
5. certification error-gate audit.

## 1.6 Smooth \(C_c^\infty\) basis pathway

The project replaced the triangular toy basis direction with the smooth log-bump family:

\[
\phi_{c,w}(x)=\psi((\log x-c)/w),
\]

where

\[
\psi(u)=
\begin{cases}
\exp(-1/(1-u^2)), & |u|<1,\\
0, & |u|\ge1.
\end{cases}
\]

The project proved:

\[
\phi_{c,w}\in C_c^\infty(0,\infty)
\]

and

\[
\operatorname{supp}(\phi*\phi^*)\subset[e^{-2w},e^{2w}].
\]
