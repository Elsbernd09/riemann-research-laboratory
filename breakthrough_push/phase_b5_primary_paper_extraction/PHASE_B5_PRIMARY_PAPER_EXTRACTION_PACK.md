# Phase B5 — Primary Paper Extraction Pack

## Purpose

Phase B4 identified serious prior-art collision risk.

Phase B5 creates the source-extraction framework needed to compare this project directly against primary literature.

The goal is to stop relying on summaries and extract exact definitions from papers.

---

# 1. Papers to extract

The priority source targets are:

1. Weil — explicit formula / Weil criterion.
2. Bombieri-Lagarias — Li criterion and multiplicative convolution setup.
3. Connes — trace formula / spectral interpretation.
4. Connes-Consani-Moscovici / van Suijlekom — finite Galerkin matrix framework.
5. Suzuki — screw-function formulation.
6. Burnol / Yoshida — local positivity or finite-range positivity.

---

# 2. Extraction fields

For every paper, extract:

1. exact test function space;
2. exact involution/star convention;
3. exact multiplicative convolution convention;
4. exact Mellin transform convention;
5. exact explicit formula functional;
6. exact positivity theorem;
7. pole-removal or admissibility constraints;
8. matrix/truncation/Galerkin object, if any;
9. overlap with our framework;
10. possible remaining gap.

---

# 3. The main collision question

The central question is:

\[
\boxed{
\text{Does prior work already contain our finite pole-admissible matrix/certificate framework?}
}
\]

If yes, our project becomes a reconstruction/prototype.

If no, the possible contribution is:

\[
\boxed{
\text{a pole-admissible arithmetic certificate pipeline for finite Weil/Bombieri test spaces.}
}
\]

---

# 4. Required standard for a breakthrough claim

A breakthrough claim requires all of the following:

1. primary-source convention lock;
2. direct comparison to finite Galerkin literature;
3. a genuinely new theorem or certified method;
4. expert review;
5. no hidden contradiction with known Weil criterion machinery.

Until then:

\[
\boxed{
\text{BREAKTHROUGH\_NOT\_ACHIEVED}
}
\]

---

# 5. Extraction workflow

For each source:

1. paste/upload the paper or relevant pages;
2. fill one extraction file;
3. mark exact formulas;
4. compare against our project;
5. classify overlap:
   - identical;
   - stronger than ours;
   - weaker than ours;
   - different formulation;
   - possible gap.
