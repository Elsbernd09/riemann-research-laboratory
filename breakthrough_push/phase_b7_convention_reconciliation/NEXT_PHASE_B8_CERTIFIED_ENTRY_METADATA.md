# Next Phase B8 — Certified Entry Metadata

## Goal

Before computing certified arithmetic entries, create a mandatory metadata wrapper.

## Every future entry must include

1. normalization label;
2. Mellin convention;
3. involution convention;
4. convolution convention;
5. constant-term convention;
6. pole-constraint status;
7. certification status;
8. error bounds.

## Boundary

No certified matrix entry is valid without metadata.
