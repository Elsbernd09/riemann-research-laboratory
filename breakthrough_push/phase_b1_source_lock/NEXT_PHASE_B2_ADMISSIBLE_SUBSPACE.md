# Next Phase B2 — Admissible Finite Subspace

## Goal

Modify the finite-dimensional framework so test functions satisfy the pole-removal constraints:

\[
\widehat g(0)=0,\qquad \widehat g(1)=0.
\]

## Required objects

1. finite basis \(\phi_j\);
2. Mellin values \(\widehat{\phi_j}(0)\), \(\widehat{\phi_j}(1)\);
3. constraint matrix \(C\);
4. nullspace basis \(N\);
5. restricted matrix \(N^*MN\).

## Why this matters

This moves the project closer to the actual Weil criterion.
