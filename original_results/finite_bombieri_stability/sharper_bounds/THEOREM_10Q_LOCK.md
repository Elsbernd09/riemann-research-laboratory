# Theorem 10Q Lock

## Weighted perturbation radius

\[
\mathcal R(\Gamma,\widetilde\Gamma,t)
=
L_t(U)
\left(
\sum_{j,k}m_jm_k(d_j+d_k)^2
\right)^{1/2}.
\]

## Main sharper certificate

\[
\mathcal R(\Gamma,\widetilde\Gamma,t)<g_0(M(\Gamma,t))
\]

implies

\[
n_-(M(\widetilde\Gamma,t))
=
n_-(M(\Gamma,t)).
\]

## Uniform-displacement sharper certificate

Let

\[
M_{\mathrm{tot}}=\sum_jm_j.
\]

If

\[
d_j\leq\delta
\]

for all \(j\), then the sharper sufficient certificate is

\[
2L_t(U)M_{\mathrm{tot}}\delta<g_0(M(\Gamma,t)).
\]

## Comparison

Since

\[
M_{\mathrm{tot}}\leq Nm_{\max},
\]

the new certificate improves the old Phase 10L certificate

\[
2Nm_{\max}L_t(U)\delta<g_0(M).
\]

## Boundary

This theorem does not prove RH.

This theorem does not falsify RH.

This theorem does not use zeta zeros.

This theorem does not claim novelty.
