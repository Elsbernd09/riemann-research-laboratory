# Why strict improvement is possible

The old certificate uses

\[
Nm_{\max}
\]

as a worst-case total multiplicity proxy.

The new uniform certificate uses

\[
M_{\mathrm{tot}}.
\]

Since

\[
M_{\mathrm{tot}}\leq Nm_{\max},
\]

the new uniform certificate is always at least as sharp.

The fully weighted certificate can be sharper still because it uses the actual displacement vector

\[
d_j=|\widetilde\alpha_j-\alpha_j|.
\]
