# Boundary and Framing Statement

## Correct framing

This project is a finite-dimensional stability note for negative eigenvalue counts in normalized Bombieri-style matrix models.

It proves a support-perturbation certificate:

\[
2Nm_{\max}L_t(U)\delta<g_0(M(\Gamma,t))
\implies
n_-(M(\widetilde\Gamma,t))=n_-(M(\Gamma,t)).
\]

## What the project may claim

The project may claim:

1. finite-dimensional theorem/proof work;
2. a stability certificate for negative eigenvalue counts;
3. a support-perturbation model;
4. a professor-readable research note draft;
5. honest separation between finite computation and RH claims.

## What the project may not claim

The project may not claim:

1. proof of RH;
2. falsification of RH;
3. verification of zeta zeros;
4. a new RH criterion;
5. a breakthrough;
6. one of the greatest RH contributions in decades;
7. novelty before expert and prior-art review;
8. guaranteed college admissions impact.

## Admissions-safe framing

A safe description is:

"I built a finite-dimensional stability framework for negative eigenvalue counts in Bombieri-style matrix models, proved a support-perturbation certificate, and prepared the result for expert review while explicitly separating finite computation from RH claims."
