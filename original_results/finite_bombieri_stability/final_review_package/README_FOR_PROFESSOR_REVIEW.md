# Professor Review Package

## Project title

Support-Stability Certificates for Negative Eigenvalue Counts in Finite Bombieri-Style Matrix Models

## Author

Michael Elsbernd

## Purpose

This package contains a finite-dimensional research note draft and supporting audit files.

The project studies stability certificates for negative eigenvalue counts in finite normalized matrix models inspired by Bombieri/Weil-style positivity frameworks.

The project does not claim progress on the Riemann Hypothesis.

---

# Main theorem

For a finite normalized matrix

\[
M(\Gamma,t)=D^{1/2}A(\Gamma,t)D^{1/2},
\]

where

\[
A(\Gamma,t)_{jk}=H_t(\alpha_j,\alpha_k),
\]

if support points satisfy

\[
|\widetilde\alpha_j-\alpha_j|\leq\delta
\]

and the kernel is locally Lipschitz with constant \(L_t(U)\), then the certificate

\[
2Nm_{\max}L_t(U)\delta<g_0(M(\Gamma,t))
\]

implies

\[
n_-(M(\widetilde\Gamma,t))=n_-(M(\Gamma,t)).
\]
