# Transfer Theorem Lock

## Theorem 10AK.1

ABSTRACT_POSITIVITY_TRANSFER_THEOREM

If

\[
Q_N(P_Nf)\to Q(f)
\]

and all sufficiently large finite forms are nonnegative, then the infinite form is nonnegative.

## Theorem 10AK.2

NEGATIVE_DIRECTION_DETECTION_THEOREM

If

\[
Q(f)\leq-\eta
\]

and

\[
|Q_N(P_Nf)-Q(f)|<\eta/2,
\]

then

\[
Q_N(P_Nf)<-\eta/2.
\]

## Theorem 10AK.3

CERTIFIED_FINITE_NEGATIVITY_THEOREM

If a computed finite matrix has a negative Rayleigh quotient below the perturbation margin, then the exact finite form has a true negative direction.
