# Next Phase 10AP — Convergence Theorem Skeleton

## Goal

Build the theorem skeleton for the missing bridge:

\[
Q_N(P_Nf)\to Q_W(f).
\]

## Types of convergence to compare

1. Pointwise convergence for each fixed \(f\).
2. Uniform convergence over a bounded class of test functions.
3. Operator-norm convergence after representing forms on a Hilbert space.
4. Strong form convergence.
5. Quantitative convergence with computable error.

## Why this matters

A finite stability theorem becomes RH-relevant only if finite forms approximate the true infinite Weil/Bombieri form.

## Expected output

Phase 10AP should not pretend to prove convergence.

It should define the exact convergence theorem we need and identify the assumptions needed to prove it.
