# Boundary and Limitations

## What this project is

This project is a finite-dimensional stability framework for negative eigenvalue counts in finite Bombieri-style matrix models.

It includes:

1. an explicit finite \(H\)-kernel;
2. compact-domain Lipschitz constants;
3. support perturbation radii;
4. a spectral-gap stability certificate;
5. a certified algorithm.

## What this project is not

This project is not:

1. a proof of RH;
2. a disproof of RH;
3. a new RH criterion;
4. a zeta-zero verification;
5. an infinite-dimensional Weil-form theorem;
6. a novelty claim;
7. a breakthrough claim.
