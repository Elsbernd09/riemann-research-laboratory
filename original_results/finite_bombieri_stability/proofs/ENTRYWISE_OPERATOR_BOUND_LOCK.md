# Entrywise Operator Bound Lock

## Locked bound

If

\[
|E_{jk}|\leq \varepsilon
\]

for all entries of an \(N\times N\) complex matrix \(E\), then

\[
\|E\|_2\leq N\varepsilon.
\]

---

# Proof mechanism

The proof uses:

\[
\|E\|_2\leq \|E\|_F
\]

and

\[
\|E\|_F
=
\left(\sum_{j,k}|E_{jk}|^2\right)^{1/2}
\leq
N\varepsilon.
\]

---

entrywise kernel/implementation error
