# Hermitian Structure Theorem Lock

## Locked lemma

The finite normalized matrix

\[
\mathcal M(\Gamma,t)=D^{1/2}A(t)D^{1/2}
\]

is Hermitian if and only if

\[
H_t(\alpha_j,\alpha_k)
=
\overline{H_t(\alpha_k,\alpha_j)}
\]

on the finite distinct support.

---

# Locked corollary

Under this kernel symmetry condition, \(\mathcal M(\Gamma,t)\) is self-adjoint on

\[
\mathbb C^N
\]

with the ordinary Euclidean inner product.

---

# Use in the original-result branch

This lemma provides the admission gate for the perturbation-stability theorem.

If the finite matrix is not Hermitian, the theorem does not apply.
