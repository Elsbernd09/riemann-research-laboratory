# Phase 10C Symmetry Summary

## Main decision

The original-result branch will define and use explicit finite symmetry classes instead of leaving \(\Gamma\) arbitrary.

## Most important class

The preferred class is quartet closure:

\[
\gamma\mapsto \gamma,\overline{\gamma},-\gamma,-\overline{\gamma}.
\]

## Why

This prevents hidden asymmetry from contaminating finite eigenvalue-count experiments.

## Connection to the theorem

The perturbation theorem will apply to Hermitian matrices built from these finite classes.

The theorem stabilizes negative eigenvalue count under perturbation.

It does not prove RH.
