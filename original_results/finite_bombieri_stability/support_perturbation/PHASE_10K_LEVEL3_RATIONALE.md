# Phase 10K Level 3 Rationale

## Why the Phase 10G result was not enough

The Phase 10G theorem is correct, but it begins with an entrywise matrix perturbation assumption.

That makes it close to standard finite-dimensional perturbation theory.

## Why support perturbation is stronger

A finite kernel matrix is generated from support points.

Therefore, a stronger theorem should begin with

\[
\alpha_j\mapsto \widetilde\alpha_j
\]

and derive a matrix perturbation estimate.

This moves the result closer to the finite Bombieri-style model.

## Level 3 target

The Level 3 target is:

\[
\texttt{SUPPORT_PERTURBATION_STABILITY_THEOREM}
\]

with certificate

\[
2Nm_{\max}L_t(U)\delta<g_0(M).
\]
