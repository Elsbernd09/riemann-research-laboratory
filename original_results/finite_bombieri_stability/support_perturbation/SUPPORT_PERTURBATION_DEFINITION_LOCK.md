# Support Perturbation Definition Lock

## Original support

\[
\Gamma_{\mathrm{dist}}=\{\alpha_1,\ldots,\alpha_N\}.
\]

## Perturbed support

\[
\widetilde\Gamma_{\mathrm{dist}}
=
\{\widetilde\alpha_1,\ldots,\widetilde\alpha_N\}.
\]

## Perturbation size

\[
|\widetilde\alpha_j-\alpha_j|\leq\delta
\]

for all \(j\).

## Same multiplicities

The perturbed support uses the same multiplicities

\[
m_1,\ldots,m_N.
\]

## Lipschitz kernel assumption

There is a finite constant

\[
L_t(U)
\]

such that

\[
|H_t(x',y')-H_t(x,y)|
\leq
L_t(U)(|x'-x|+|y'-y|)
\]

for all \(x,y,x',y'\in U\).

## Locked support-level certificate candidate

\[
2Nm_{\max}L_t(U)\delta<g_0(M)
\]

should imply

\[
n_-(M(\widetilde\Gamma,t))=n_-(M(\Gamma,t)).
\]
