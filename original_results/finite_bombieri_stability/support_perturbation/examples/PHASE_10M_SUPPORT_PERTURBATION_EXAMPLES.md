# Phase 10M — Support-Perturbation Examples and Certificates

## Purpose

Phase 10L proved the support-perturbation stability theorem.

Phase 10M generates synthetic examples showing:

1. a support perturbation certified stable by Theorem 10L;
2. a failed certificate where the count happens to remain stable;
3. a failed certificate where the count changes;
4. the effect of multiplicity weights.

---

# Certificate

The support-level certificate is

\[
2Nm_{\max}L_t(U)\delta<g_0(M(\Gamma,t)).
\]

When this holds,

\[
n_-(M(\widetilde\Gamma,t))=n_-(M(\Gamma,t)).
\]

---

# Toy kernel

The examples use the synthetic toy kernel

\[
H(x,y)=x+y.
\]

This is not the zeta kernel.

It is used only to illustrate the support-perturbation theorem.

---

# Example interpretation

The examples show that Theorem 10L is a sufficient condition.

If the certificate passes, stability is guaranteed.

If the certificate fails, stability may or may not hold.

---

# Boundary

These are synthetic finite examples.

This phase does not prove RH.

This phase does not falsify RH.

This phase does not use zeta zeros.

This phase does not verify the zeta case.

This phase does not claim novelty.
