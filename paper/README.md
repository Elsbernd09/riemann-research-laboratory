## Central theorem

Fix

\[
\eta>0
\]

and a compact interval

\[
K\Subset(0,\infty).
\]

Let

\[
B=(1+\eta)H.
\]

For positive integers \(n\) satisfying

\[
n/H\in K,
\]

define the global interior zero-counting discrepancy response

\[
R_{\mathrm{int}}(n;H,\eta)
=
-
\int_H^B
E(t)\chi_n'(t)\,dt,
\]

where

\[
E(t)=N(t)-M(t)
\]

and

\[
\chi_n(t)=\chi_n^{Li}(t).
\]

The project proves

\[
\boxed{
R_{\mathrm{int}}(n;H,\eta)
=
O_{K,\eta}
\left(
\frac{\log H}{H^3}
\right)
}
\]

uniformly for

\[
n/H\in K.
\]

No assumption of the Riemann Hypothesis is used.

Consequently,

\[
\boxed{
H^2R_{\mathrm{int}}(n;H,\eta)\to0.
}
\]

Under RH, the classical sharper first-primitive estimate yields

\[
\boxed{
R_{\mathrm{int}}(n;H,\eta)
=
O_{K,\eta}
\left(
\frac{\log H}
{H^3(\log\log H)^2}
\right).
}
\]

## Main mathematical mechanism

The proof has four components:

1. the classical first-antiderivative control of the zero-counting argument term;

2. the matched-scale Li susceptibility derivative hierarchy;

3. the centered discrepancy primitive;

4. an exact second-order integration-by-parts transfer identity.
