# 2. Classical Inputs

## 2.1 Riemann-von Mangoldt decomposition

Let

\[
N(t)
\]

denote the number of nontrivial zeros

\[
\rho=\beta+i\gamma
\]

with

\[
0<\gamma\le t,
\]

counted with multiplicity.

Define

\[
M(t)
=
\frac{t}{2\pi}
\log\frac{t}{2\pi e}
+
\frac78.
\]

The classical zero-counting formula gives

\[
N(t)
=
M(t)
+
S(t)
+
R(t),
\]

with

\[
R(t)=O(1/t).
\]

Hence

\[
E(t)
=
N(t)-M(t)
=
S(t)+R(t).
\]

The proof below uses ordinary integrals of \(E\).

Therefore changes to point values at isolated zero ordinates do not affect the main theorem.

Stieltjes atom identities are a separate matter and require synchronized endpoint conventions.

## 2.2 First primitive of the argument term

Define

\[
S_1(t)
=
C+\int_0^tS(u)\,du.
\]

We use the classical unconditional estimate

\[
\boxed{
S_1(t)=O(\log t).
}
\]

Under RH, we use the classical sharper estimate

\[
\boxed{
S_1(t)
=
O
\left(
\frac{\log t}
{(\log\log t)^2}
\right).
}
\]

These estimates are classical inputs.

They are not proved in this paper.

## 2.3 Prior-art boundary

The following are classical:

- Riemann-von Mangoldt zero counting;
- the argument term \(S(t)\);
- the first primitive \(S_1(t)\);
- unconditional and RH-conditional control of \(S_1\);
- integration by parts;
- the Li kernel;
- the Guinand-Weil explicit-formula interpretation of Li coefficients.

The paper's theorem is a specialization obtained by combining these classical inputs with the project Li susceptibility derivative hierarchy and centered-primitive response decomposition.

Originality of the full specialization remains under active prior-art review.
