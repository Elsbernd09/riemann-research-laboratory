# 7. Numerical Motivation and Finite-Height Validation

## 7.1 Role of computation

The numerical work in this project is not used to prove Theorem A.

Its purpose is:

1. to motivate the centered-primitive decomposition;

2. to test finite-height response geometry;

3. to validate exact numerical identities;

4. to compare finite observed response with continuum and transfer predictors.

---

## 7.2 First zero block

The first numerical block used the first 500 computed critical-line ordinates.

The finite dataset was generated at high precision and every stored ordinate was checked numerically against the zeta function.

This finite dataset does not prove RH.

It does not prove completeness of all zeros.

It is a computational dataset.

---

## 7.3 Disjoint higher-zero replication

A second numerical block used zero indices 501 through 1500.

The component-share geometry was tested against a principal axis frozen from the first block before the higher-block response shares were generated.

The higher block showed strong finite numerical replication of the near-one-dimensional component-share geometry.

This is internal disjoint-index replication.

It is not statistical independence.

It is not an asymptotic theorem.

---

## 7.4 Centered-primitive compression

The numerical centered-primitive certificate showed strong compression relative to the first absolute transfer scale.

The experiments motivated the analytic question:

Can the centered discrepancy primitive be bounded from classical zero-counting theory?

Theorem A answers this asymptotically using the classical unconditional estimate

\[
S_1(t)=O(\log t).
\]

Thus the computation motivated the theorem.

It does not replace the theorem.

---

## 7.5 PCA interpretation

The finite component-share cloud concentrated strongly near the edge

\[
i=0.
\]

The learned principal direction was nearly the atom-endpoint exchange direction.

The paper does not present PCA as a mathematical theorem.

The asymptotic theorem is

\[
R_{\mathrm{int}}
=
o(H^{-2}).
\]

On nondegenerate competing-channel paths, this provides an analytic mechanism consistent with the observed small-interior geometry.
