# Next Phase X15 — Prime-Side Interval Certificate

## Goal

Certify the finite prime side:

\[
\sum_{n\le N}\Lambda(n)(F(n)+\widetilde F(n)).
\]

## Required

1. finite cutoff from X4;
2. exact von Mangoldt values;
3. interval enclosures for \(F(n)\);
4. interval enclosures for \(\widetilde F(n)\);
5. finite interval sum.

## Remaining issue

\(F(n)\) is itself a convolution integral, so prime-side certification requires certified pointwise convolution enclosures.
