# Phase X15 — Prime-Side Interval Certificate

## Purpose

Phase X15 attacks the finite prime side of the locked Bombieri–Lagarias functional:

\[
\sum_{n\le N}\Lambda(n)\left(F(n)+\widetilde F(n)\right).
\]

Earlier phases proved that the prime side is finite once the support of \(F\) is known.

Now we create the finite prime-side interval certificate structure.

---

# 1. Locked prime side

For:

\[
F=\Phi*\Phi^*,
\]

the prime side is:

\[
P(F)=
\sum_{n=1}^{N}
\Lambda(n)\left(F(n)+\widetilde F(n)\right),
\]

where:

\[
\widetilde F(n)=n^{-1}F(1/n).
\]

The finite cutoff is:

\[
N=\left\lfloor \max(B,A^{-1})\right\rfloor
\]

when:

\[
\operatorname{supp}(F)\subset[A,B].
\]

---

# 2. Prime-side interval structure

For each integer \(n\le N\), we need intervals:

\[
F(n)\in[L_n,U_n],
\]

and:

\[
\widetilde F(n)\in[\widetilde L_n,\widetilde U_n].
\]

Then:

\[
\Lambda(n)\left(F(n)+\widetilde F(n)\right)
\]

has an interval enclosure.

Summing finitely many interval terms gives an interval enclosure for \(P(F)\).

---

# 3. Honest blocker

The values \(F(n)\) and \(F(1/n)\) are convolution values:

\[
F(x)=\int \Phi(y)\Phi^*(x/y)\frac{dy}{y}.
\]

This phase creates interval wrappers around pointwise convolution evaluations.

However, the pointwise convolution evaluation is not yet fully certified by interval quadrature.

Therefore the status is:

\[
\boxed{
\texttt{PRIME\_SIDE\_INTERVAL\_CERTIFICATE\_POINTWISE\_CONVOLUTION\_NOT\_CERTIFIED}
}
\]

# Theorem X15.1 — finite prime-side interval summation

Suppose for every \(n\le N\) we have intervals:

\[
F(n)\in I_n,
\qquad
\widetilde F(n)\in J_n.
\]

Then interval arithmetic applied to:

\[
\sum_{n\le N}\Lambda(n)(I_n+J_n)
\]

encloses the true finite prime side:

\[
P(F)=\sum_{n\le N}\Lambda(n)(F(n)+\widetilde F(n)).
\]

## Proof

For each \(n\), interval addition encloses:

\[
F(n)+\widetilde F(n).
\]

Multiplication by the nonnegative scalar \(\Lambda(n)\) preserves enclosure.

Finite interval summation preserves enclosure.

Therefore the total interval contains the true finite sum.

\[
\square
\]

---

# Theorem X15.2 — prime-side certificate is incomplete without pointwise convolution certificates

If each \(F(n)\) is generated by an uncertified pointwise convolution approximation, then the resulting prime-side interval is not a fully certified prime-side certificate.

## Proof

The finite interval summation theorem assumes valid input intervals for \(F(n)\) and \(\widetilde F(n)\).

If those intervals are produced by uncertified pointwise convolution approximations, the hypothesis is not fully proven.

Therefore the prime-side interval structure exists, but full prime-side certification remains incomplete.

\[
\square
\]
