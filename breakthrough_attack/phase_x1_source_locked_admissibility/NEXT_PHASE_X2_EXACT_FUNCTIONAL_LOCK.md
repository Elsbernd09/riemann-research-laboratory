# Next Phase X2 — Exact Functional Lock

## Goal

Define one exact functional:

\[
T_{BL}[f]
\]

using one convention only.

## Use

Bombieri–Lagarias normalization unless a primary source proves a transformation.

## Required

1. tilde convention;
2. convolution convention;
3. Mellin convention;
4. explicit formula;
5. constant term;
6. pole term status;
7. archimedean term;
8. prime term.

## Rule

No more mixed \(4\pi\) and \(\pi\) constants.

No more switching between \(g^*\), \(f^\vee\), and \(\widetilde f\) without a dictionary.
